# Projeto Conversor de Moeda

Este projeto é um conversor de moedas simples desenvolvido em HTML, CSS e JavaScript. Ele permite ao usuário converter valores entre diferentes moedas, utilizando uma interface intuitiva e imagens representando cada país.

## Funcionalidades
- Conversão entre moedas (Real, Dólar, Euro, Peso Argentino)
- Interface amigável e responsiva
- Imagens das bandeiras dos países

## Estrutura do Projeto
```
index.html        # Página principal do conversor
script.js         # Lógica de conversão e manipulação do DOM
style.css         # Estilos da interface
photos/           # Imagens das bandeiras
  ar.png          # Argentina
  br.png          # Brasil
  es.png          # Espanha
  us.png          # Estados Unidos
```

## Como usar
1. Abra o arquivo `index.html` em um navegador web.
2. Selecione a moeda de origem e destino.
3. Insira o valor a ser convertido.
4. Clique no botão para ver o resultado da conversão.
